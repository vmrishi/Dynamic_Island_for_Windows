Orbit Island 0.4

Release checks:
- Windows x64 WPF build / compiled Theme.xaml.
- 34 portable regression checks with built-assembly inspection:
  persistence and recovery; notch preferences/bounds/locale coordinates;
  previous-app attribution, switch counts, idle/excluded/paused/out-of-order
  samples, suspend gaps, hour/midnight splits, consistent seven-day ranges,
  duration formatting, matching foreground media sources; calendar leap dates,
  invalid input and overnight duration; responsive bounds/aspect ratio;
  escaped WLAN profiles and enterprise rejection; Wi-Fi/Bluetooth native x64
  structure sizes; embedded standard icon data and compiled WPF resources.
- Self-contained runtime/dependency manifest and ZIP integrity checked at packaging.

Not run on Linux:
- WPF screen rendering, hover/click/keyboard/DPI behavior or screenshot matching.
- Actual browser/media sessions and transport commands.
- Bluetooth profile toggles/pairing, WLAN joins/scans, audio-policy device changes.
- DDC/CI/WMI monitor operations, desktop screenshot capture, Windows notifications.
- Live Open-Meteo or Ollama requests.

Windows-only visual/geometry regression checks are in Capture-UI.ps1.
Native ABI and profile-XML checks validate structure/logic, not hardware behavior.
